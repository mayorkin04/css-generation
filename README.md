# 🎨 Генератор градиентов

Красивый и удобный инструмент для создания CSS-градиентов прямо в браузере. Никаких зависимостей, полностью локальная работа — без отправки данных на сервер.

## ✨ Возможности

- **Визуальный предпросмотр** – мгновенное отображение градиента на всей области предпросмотра.
- **Выбор начального и конечного цветов** – встроенный палитра с возможностью ввода HEX‑кода.
- **Настройка угла** – ползунок от 0° до 360° и быстрые кнопки‑пресеты (0°, 45°, 90° и т.д.).
- **Случайный градиент** – генерация случайных цветов и угла одним кликом.
- **CSS‑код** – автоматически формируется строка `background: linear-gradient(...)` с подсветкой синтаксиса.
- **Копирование в буфер обмена** – кнопка «Копировать» с визуальным подтверждением.
- **Современный тёмный интерфейс** – «стеклянные» карточки, неоновая типографика, текстура шума.
- **Адаптивная вёрстка** – комфортно смотрится на мобильных устройствах.

## 🚀 Демо

Просто откройте файл [index.html](index.html) в любом современном браузере.  
Градиент можно менять мгновенно — все вычисления происходят на вашей машине.

## 🛠 Использование

1. **Выбор цветов** – кликните по квадрату с цветом или измените значение вручную в поле HEX.
2. **Угол градиента** – перетащите ползунок или нажмите на один из пресетов.
3. **Случайный градиент** – нажмите кнопку «⟳ Случайный градиент».
4. **Копирование CSS** – кликните по кнопке «Копировать» в блоке кода. Готовую строку можно сразу вставить в ваш проект.
